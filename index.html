ABOUT THE SYSTEM

Monitoring System Threat is a centralized monitoring platform designed to provide administrators with a clear view of authorized computers and security events within a network environment.

The system is designed to organize monitoring information, identify potential threats, and present security-related data through an intuitive dashboard.
